CreditLens — End-to-End Loan Risk Analytics Pipeline
One chain, five skills: data sourcing → cloud storage → Python cleaning → ML scorecard → SQL analysis → dashboard → public proof
Step 1 · Source
Loan Dataset
30,500+ personal-loan records with grades A–G, income, DTI, purpose, state and a default flag (Kaggle CSV or the seeded generator).
loans_raw.csv
Step 2 · Cloud
AWS S3
Raw and cleaned files stored in a Free-Tier bucket — durable, versioned landing zone for the pipeline.
s3://creditlens-raw
Step 3 · Clean
Python + Pandas
Types fixed, 180 duplicates removed, target-missing rows dropped, group-median imputation, outliers capped — every decision logged.
clean_loans.py → clean_loans.csv
Step 4 · Model
Python + scikit-learn
WOE/IV feature binning, logistic scorecard validated on a 30% holdout (AUC 0.776 — beats FICO, nearly matches the bank's own grade), every loan scored.
risk_model.py → loans_scored.csv
Step 5 · Analyse
SQLite
Clean data plus the model score table; 20 business questions answered with one commented query each — NTILE deciles, window functions, expected loss.
loans.db + analysis.sql
Step 6 · Present
Power BI / ECharts
4-page dashboard reading live from the SQL layer: Overview, Risk Deep-Dive, Loan Explorer and a Model & Scorecard page with ROC / KS / WOE.
creditlens_dashboard
Step 7 · Publish
GitHub
Clean folder structure, README with architecture, screenshots and six data-backed insights recruiters can verify.
README.md + sql/results/
Total cost: $0 AWS S3 Free Tier Python + SQLite Power BI Desktop / ECharts (offline HTML) GitHub
